# 基金持仓净变动测算（拆股 / 换股折算）

Flask + SQLite 网页应用：上传同一基金前后两期完整持仓 CSV 与换股公告 CSV，
按公告逐日折算期初持仓，按期末代码输出折算来源、折算股数、实报股数与净变动。

## 折算规则

- 公告区间为 **(期初日, 期末日]**：期初日次日起生效，期末日当天含在内；
  期末持仓尚未上传时窗口上不封顶（预览），上传后再约束到期末日。
- 同日、同一旧代码最多一条公告（上传时强校验，违规整表拒绝）。
- 每个交易日先**冻结当日起始余额**，所有折算基于起始余额；
  **新换得的份额当天不再折算**，日内转换在收盘阶段统一结算。
  例如同日 `A→B (1:2)`、`B→C (1:5)`：A 换入的 B 当天保留，
  只有 B 的起始余额被折成 C。
- 全程 `Decimal` 运算，**中间不取整、不截断**；份额以规范化字符串入库。
- 净变动 = 实报股数 − 折算股数；折算侧或实报侧缺项一律按零计算。
- 同一期末代码由多个期初来源合并时，逐来源展示折算路径与份额。

## CSV 格式

持仓 CSV（表头支持中英文别名，证券代码按文本保留前导零）：

```
证券代码,股数
000001,100
000002,200
```

公告 CSV（新旧股数比 = 每 1 股旧代码换得的新代码股数）：

```
生效日,旧代码,新代码,新旧股数比
2026-01-15,000001,000001X,3
```

## 公告整表换报与增量重算

- 公告按整表替换：新表先解析校验，失败仅登记 `failed` 批次，
  原 `active` 表与既有结果完全不动、仍可查询。
- 换报时用代码级轻量模拟（只跟踪代码、不算股数）对比新旧公告，
  **只对可能受改动影响的期初持仓做完整股数重算**，
  未受影响来源沿用上一结果批次的折算行，结果批次中注明重算/沿用条数。
- 公告批次（active / superseded / failed）与全部历史结果批次均可在页面查回。
- 持仓同周期重复上传按整表替换，自动触发全量重算；历史持仓文件保留。

## 公告回查（结果页按生效日 + 旧代码追溯来源）

在任一**结果批次详情页**（历史版本里点“查看”也可）输入公告**生效日**与**旧代码**，
从该批次已保存的 `result_lot` 明细中找出**经过这条公告的期初来源**：

- 明细只列命中的来源，给出每条来源的**完整折算路径**与**折算股数**；
  查无匹配时显示空结果。
- 命中来源所对应的**期末证券**，其折算总股数、实报股数、净变动**沿用该批整表数值**
  （与净变动表逐字一致，不另行重算）。
- 回查始终绑定 URL 中的结果批次：另一窗口上传持仓或换报后，原页面仍按所选批次取数，
  不会串到新批次。
- **首次回查自动准备该批查询数据**（把每条来源路径中的公告步骤展开进 `lookup_index`）；
  也可点“准备/重试”手动准备。准备失败只登记 `failed`，**原表（result_lot）照查并可重试**。
- 准备结果持久化在 SQLite 中，**服务重启后直接走索引查询**；
  旧库无需重传，新表由建表脚本以 `CREATE TABLE IF NOT EXISTS` 自动补齐。
- 旧代码按文本处理，保留前导零。

## 本地运行

```bash
pip install -r requirements.txt
python run.py            # http://127.0.0.1:8000
```

## Docker Compose 启动

```bash
docker compose up --build -d
# 打开 http://localhost:8000
```

SQLite 数据库与上传的原始 CSV 持久化在命名卷 `fund-data`（容器内 `/data`）。
单 gunicorn worker + 多线程，配合 SQLite WAL。

## 测试

```bash
python -m pytest tests/ -q
```

覆盖：折算引擎（拆股、日期边界、同日链、合并、不取整）、
服务层（净变动缺项按零、换报增量、换报失败可查、重复代码拒绝）、
公告回查（首次自动准备、索引/原表扫描、失败回退与重试、重启持久化、批次隔离、空结果）、
网页端到端（上传、换报、回查、flash 提示）。

## 目录

```
app/engine.py      折算引擎（纯函数，Decimal）
app/csv_utils.py   CSV 解析与校验
app/db.py          SQLite schema 与连接管理（含 lookup_prep / lookup_index 回查表）
app/services.py    上传/换报/增量重算/净变动查询/公告回查（准备索引、回退扫描）
app/routes.py      网页路由（含 /results/<id>/prepare-lookup）
app/templates/     单页界面
tests/             pytest 测试
```
